Resolve

A knowledge base for publishing offices. Ask a question and get an answer with citations, taken only from each journal's latest stylesheet and from ticket answers a lead has approved.

Open Resolve → Read the code
  • A revised stylesheet retires the old one, so superseded rules cannot be quoted.
  • One journal's rules never appear in another's, enforced in the database.
  • When the sources do not answer, it says so and offers a ticket.
  • Works inside AI tools such as Claude through an MCP server with real sign-in.
