First product

Resolve: answers that cite their sources.

Early · built solo

A knowledge base for publishing offices.

Ask a question, get an answer with citations, taken only from each journal's latest stylesheet and from ticket answers a lead has approved. When it doesn't know, it says so and offers to raise a ticket.

  • A revised stylesheet retires the old one, so superseded rules can't be quoted.
  • One journal's rules never appear in another's, enforced in the database.
  • 168 trap questions on synthetic data: 95.8% correct, with no stale or wrong-journal answers.
  • Works inside AI tools such as Claude through an MCP server with real sign-in.
Open Resolve Read the code How it works

Resolve is an independent project, written in my own time. It uses synthetic data only: no employer code, documents or data are involved. Accounts are by request; the sign-in page has a short form.

How I build

Boring where it should be, careful where it counts.

Measure it

If a tool claims it's accurate, I'd rather show the test than the adjective. Resolve ships its own evaluation harness, results included.

Keep it boring

One Postgres, a plain API, standard sign-in. Fewer moving parts means fewer 2 a.m. surprises for whoever runs it.

Respect the data

Manuscripts are unpublished work. Documents stay on your own server, and the AI sees only what a question needs.
